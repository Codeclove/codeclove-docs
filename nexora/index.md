# Nexora School ERP

**Nexora** is a self-hosted school management system built specifically for WordPress. It handles the complete operational lifecycle of schools, institutes, and academies without monthly per-student SaaS fees.

---

## Core Capabilities

* **Academic Structure:** Support for multiple academic sessions, terms, classes, and sections with pre-configured templates for Indian school boards (CBSE, ICSE, State Boards) and international curriculums.
* **Student Admissions:** Public-facing application forms, document verification workflows, and single-click applicant-to-student conversion.
* **Fee Management:** Itemized fee heads, flexible payment schedules (annual, term-wise, monthly), invoice generation, and receipt tracking.
* **Student Information System (SIS):** Complete student profiles, parent/guardian records, emergency contacts, and academic history.

---

## System Requirements

Nexora runs on standard WordPress hosting environments. Before installing, ensure your server meets the following minimum specifications:

| Requirement | Minimum | Recommended |
|---|---|---|
| **WordPress** | 6.2+ | Latest stable (6.7+) |
| **PHP Version** | 8.0+ | PHP 8.2 or 8.3 |
| **MySQL / MariaDB** | MySQL 5.7+ / MariaDB 10.3+ | MySQL 8.0+ / MariaDB 10.6+ |
| **PHP Memory Limit** | 128 MB | 256 MB or higher |
| **PHP Extensions** | `curl`, `json`, `mbstring`, `zip` | Standard WordPress extensions |
