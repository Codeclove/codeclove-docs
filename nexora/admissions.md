# Student Admissions

Nexora provides an end-to-end admissions workflow: from public applicant submission to document verification and single-click student conversion.

---

## 1. Publishing the Public Application Form

Nexora generates a responsive admission application form that can be embedded on any WordPress page.

1. In WordPress admin, go to **Pages > Add New Page**.
2. Title the page (e.g., `Admissions` or `Apply Online`).
3. Add the Nexora Admissions shortcode or Gutenberg block:
   ```text
   [nexora_admission_form]
   ```
4. Publish the page.

Parents and students can now submit applications, enter guardian contact info, and upload required documents (birth certificate, previous marksheet, transfer certificate).

---

## 2. Reviewing Applications

When a form is submitted, school administrators receive an email notification and the application appears in the admission pipeline:

1. Navigate to **Nexora > Admissions > Applications**.
2. Click on an applicant's name to view their complete dossier.
3. Review uploaded identity documents and previous academic records.
4. Update the application status:
   * **Under Review:** Application is undergoing verification.
   * **Interview / Test Scheduled:** Applicant is shortlisted for assessment.
   * **Approved:** Applicant is accepted for admission.
   * **Rejected / Waitlisted:** Application declined or put on standby.

---

## 3. Converting Applicants to Enrolled Students

Once an applicant is accepted and initial registration fees are paid:

1. Open the approved application record.
2. Click **Convert to Student**.
3. Select the target **Class**, **Section**, and assign a **Roll Number / Admission Number**.
4. Click **Confirm Enrollment**.

Nexora automatically creates a permanent student record in the Student Information System (SIS), linking parent contacts and documents without requiring manual data re-entry.
