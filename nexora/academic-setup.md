# Academic Setup & Board Presets

Configure your institution's academic structure, including sessions, classes, sections, and curriculum boards.

---

## 1. Academic Sessions (Years)

Nexora manages all students, attendance records, and fee invoices within designated academic sessions.

1. Navigate to **Nexora > Academic > Sessions**.
2. Click **Add New Session**.
3. Enter the session title (e.g., `2026–2027`).
4. Set the **Start Date** (e.g., `April 1, 2026`) and **End Date** (e.g., `March 31, 2027`).
5. Toggle **Set as Current Session** if this is the active operational year.
6. Click **Save Session**.

---

## 2. Using Board Presets (CBSE, ICSE, State Boards)

To save setup time, Nexora provides pre-built structures tailored for different educational boards:

1. Navigate to **Nexora > Setup Wizard** (or **Settings > Board Presets**).
2. Select your institution type:
   * **CBSE Preset:** Configures classes from Nursery through Grade 12 with standard stream definitions (Science, Commerce, Humanities).
   * **ICSE / ISC Preset:** Sets up standards I through XII with mandatory project assessment categories.
   * **Custom / Standard Preset:** Build your own custom grade levels and nomenclature.
3. Click **Apply Preset** to generate the class hierarchy automatically.

---

## 3. Creating Classes and Sections

If you prefer to configure classes manually:

1. Go to **Nexora > Academic > Classes**.
2. Click **Add Class** and enter the class name (e.g., `Class 9` or `Grade 9`).
3. Under **Sections**, define the section identifiers (e.g., `Section A`, `Section B`).
4. Assign a **Class Teacher** from your registered faculty list (optional).
5. Set maximum student capacity per section for enrollment management.
6. Click **Create Class**.
