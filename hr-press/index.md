# HR Press Pro

**HR Press Pro** is a modern Human Resource Management (HRMS) plugin for WordPress. It gives businesses, agencies, and institutions a centralized dashboard to manage employee directories, departments, roles, leave requests, and daily attendance.

---

## Core Capabilities

* **Employee Directory:** Centralized employee records, job profiles, emergency contacts, identity documents, and contract terms.
* **Organizational Structure:** Multi-level department hierarchies, custom designations, and reporting manager relationships.
* **Leave Management:** Custom leave types (Paid, Sick, Casual, Maternity), annual quota rules, multi-stage approval workflows, and holiday calendars.
* **Attendance Tracking:** Daily web clock-in/out, manual attendance overrides, and monthly timesheet reporting.

---

## System Requirements

| Requirement | Minimum | Recommended |
|---|---|---|
| **WordPress** | 6.2+ | Latest stable (6.7+) |
| **PHP Version** | 8.0+ | PHP 8.2 or 8.3 |
| **MySQL / MariaDB** | MySQL 5.7+ / MariaDB 10.3+ | MySQL 8.0+ / MariaDB 10.6+ |
| **PHP Memory Limit** | 128 MB | 256 MB or higher |
